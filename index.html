Game overview

A networking class you can walk through.

Instead of keeping every activity inside a normal menu, NetPlay places the learning experience inside a connected school campus. Every room has a purpose, and every task moves the player forward.

Explore, learn, and apply each concept in the same playable world.

The student enters lectures, completes quizzes, unlocks practical activities, and uses campus services while building progress. The instructor can monitor records and manage the academic side of the experience.

Core design goals
  1. 01Make networking concepts easier to understand through interaction.
  2. 02Connect lectures, quizzes, and laboratory work in one clear flow.
  3. 03Give students visible progress while instructors see useful records.

Core game loop

One connected path from campus entry to practical skill.

STEP 01

Explore

STEP 02

Learn

Start the lesson and review the networking concept for the current level.

STEP 03

Answer

Take the quiz to check understanding before the practical activity opens.

STEP 04

Practice

Complete a hands-on lab such as cable wiring, CIDR, pipeline, or firewall work.

Earn experience and coins, manage energy, and continue to the next objective.

Lab activities

Four activities built around practical networking skills.

Each laboratory turns a technical topic into a focused challenge with objectives, score, time, feedback, and a clear completion state. Nearby computer stations now provide flexible access to the lab activities.

01

RJ45 Cabling

Arrange the correct wire sequence, complete straight-through and crossover cables, then crimp the connector.

Skill / Cable standards
02

CIDR Challenge

Analyze network blocks and match subnet answers to the correct targets using CIDR notation.

Skill / Subnetting
03

Packet Pipeline

Build a working multi-direction path and guide network traffic through the correct sequence.

Skill / Packet flow
04

Firewall Defense

Inspect incoming packets and decide what should be allowed or blocked by the network rules.

Skill / Traffic filtering

Player systems

Progress is always visible.

The HUD keeps the player informed without leaving the game world. The objective panel explains what to do next, while resources reflect the result of each action.

LV

Level progress

Shows the current level, finished lessons, quiz performance, and the next required action.

LAB

Lab status

Tracks unlocked activities and whether each practical networking challenge has been passed.

REC

Personal record

Keeps eight levels of learning progress visible in one scrollable, non-overlapping panel.

Interaction guidance

Context-aware prompts explain what the nearby object does.

The interaction card identifies the object beside the player and describes its action. The room guide can be hidden when the player wants an unobstructed view.

  • Nearby object name and action
  • Role-aware student or instructor guidance
  • Hideable room guide and minimap
