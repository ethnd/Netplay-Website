NETPLAY WEBSITE - DEPLOYMENT AND GOOGLE SEARCH SETUP

1. Upload the complete contents of this folder to your public web host.
   Keep index.html, style.css, script.js, robots.txt, assets, and downloads together.

2. After the website has a real public URL, copy sitemap-template.xml and rename
   the copy to sitemap.xml. Replace this placeholder inside the copied file:

   https://YOUR-PUBLISHED-DOMAIN.example/

   with the exact public homepage URL, including https:// and any subfolder.

3. Add this final line to robots.txt using the same public domain:

   Sitemap: https://YOUR-PUBLISHED-DOMAIN.example/sitemap.xml

4. In index.html, add these URL-specific tags inside <head> after you know the
   actual public URL:

   <link rel="canonical" href="https://YOUR-PUBLISHED-DOMAIN.example/">
   <meta property="og:url" content="https://YOUR-PUBLISHED-DOMAIN.example/">

5. Add the public website to Google Search Console, submit sitemap.xml, inspect
   the homepage URL, and request indexing.

GAME DOWNLOAD SETUP

1. In Godot, export the project using the Windows Desktop release preset.
2. Test the exported NetPlay.exe before uploading it.
3. Keep every exported file together; do not distribute only the EXE.
4. ZIP the complete exported folder using this exact filename:

   NetPlay-Windows-v1.0.0.zip

5. Place that ZIP inside this website's downloads folder.
6. Upload the updated website. The Download button will detect the file and
   activate automatically.

Important: The included website package does not contain the game build yet.
It does not substitute a source-project ZIP or placeholder file for the game.
